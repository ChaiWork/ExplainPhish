SDK Installation & Quickstart

Welcome to the Acme Cloud SDK documentation. This guide walks you through setting up our client libraries in Python, JavaScript, and Go.

Installation via Package Manager

To get started with Python, install the official package using pip:

pip install acme-cloud-sdk

Sample Quickstart Code

Initialize the client and authenticate using your local configuration profile:

from acme import AcmeClient

client = AcmeClient(project_id="my-sample-project")
response = client.health_check()
print(f"Service status: {response.status}")
